# Start here

1. Read `docs/ARCHITECTURE.md`.
2. Read `docs/02_CONTRACTS/SOURCE_OF_TRUTH.md`.
3. Inspect `contracts/MODULE_REGISTRY.yaml` and `contracts/P3_INTEGRATION_CONTRACT_PACK_V2.yaml`.
4. Run `p3 validate`.
5. Run the deterministic test suite before changing code.

The final architecture contains foundation capabilities, runtime capabilities and orchestration. These are technical domains inside one P3 package, not separate delivery units.
