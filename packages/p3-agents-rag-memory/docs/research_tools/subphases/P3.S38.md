# P3.S38 — Company Fundamentals Tool Suite

## Scope

Provides `company.fundamentals.v1` with profile, statements, fundamental snapshot, guidance, capital allocation, peers, and explicit-assumption valuation operations. All handlers are read-only and enforce `available_at <= decision_time`.

## Design

- normalized P1/P2 snapshots only; no live API in backtests;
- as-reported values and restatements remain separate;
- readiness is resolved per operation and mode;
- scenario valuation is not a target price or recommendation;
- unavailable upstream views return `BLOCKED_UPSTREAM`.

## Integration

`P3.S40` adapts the company bundle into the existing `ToolGatewayPort`. P4/P9 outputs remain supplemental and P5 has no direct connection.
