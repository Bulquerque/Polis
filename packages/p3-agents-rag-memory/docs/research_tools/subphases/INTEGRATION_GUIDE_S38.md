# S38 Integration Guide

1. Apply the additive package to an extracted P3 baseline.
2. Build `company_operation_readiness_panel` from S33 views.
3. Build M02–M05 bundles.
4. Run M06 with contract/leakage reports.
5. Use `runtime.company_adapter.build_company_operations` and pass the operations to S40 through the `research_tool_operations` service.
6. Do not expose `BLOCKED_UPSTREAM` operation/mode combinations to agents.
