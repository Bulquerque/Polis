# Comece aqui

1. Leia `SOURCE_OF_TRUTH.md`.
2. Leia `docs/ARCHITECTURE.md` e `docs/POINT_IN_TIME_AND_BACKTEST.md`.
3. Verifique os cinco contratos em `contracts/modules/`.
4. Integre o diretório `src/` sobre o pacote P3 RC4.1.
5. Registre configurações e schemas conforme `INTEGRATION_GUIDE.md`.
6. Execute `tools/validate_package.py`.
7. Execute `tools/run_tests_safely.py`.
8. Não declare promoção produtiva: a autoridade final continua sendo P0.
