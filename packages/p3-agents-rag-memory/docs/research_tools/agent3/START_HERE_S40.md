# Start Here — P3.S40

P3.S40 is the third subphase of Agent 3. It is an additive integration patch for the P3 research-tool extension.

Read in this order:

1. `docs/research_tools/P3.S40.md`
2. `docs/research_tools/INTEGRATION_GUIDE_S40.md`
3. `contracts/research_tools/P3_S40_MODULE_IO_OVERLAY.yaml`
4. `contracts/overlays/P3_S40_INTEGRATION_OVERLAY.yaml`
5. module contracts under `contracts/research_tools/modules/`
6. test and validation reports under `reports/research_tools/runtime/`

The package does not promote itself to the canonical 81-module baseline and does not modify P3.S1–P3.S31.
