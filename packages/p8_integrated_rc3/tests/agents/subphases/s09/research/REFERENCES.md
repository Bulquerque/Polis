# Technical references

- Pydantic v2 documentation: strict typed runtime validation and JSON Schema generation.
- JSON Schema Draft 2020-12 specification.
- Python Packaging User Guide: src layout and namespace packages.
- pytest documentation: parametrized tests.
- Black-Box Simplex Architecture for Runtime Assurance (Mehmood et al.).
- Fallback-Safe MPC (Sinha, Schmerling, Pavone).
- River and Frouros repositories were reviewed as design references for streaming drift detectors. They are not runtime dependencies.

The safety-control literature is used as an architectural analogy. Its original physical-system guarantees are not claimed for financial markets.
