# Testing standards — Fase 0

Critério de término (Definition of Done): cada módulo possui oracle positivo e caso negativo, validações críticas classificadas, `test_run_id` único, evidência com lineage/hash e nenhum bloqueio de conexão, teste crítico ou qualidade.

Testes da Fase 0 devem validar documentação, contratos, schemas, module IO matrix, dashboards, reports e release gate. A Fase 0 também coleta os resultados dos testes das Fases 1–9.
