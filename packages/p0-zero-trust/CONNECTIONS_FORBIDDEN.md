# Conexões proibidas — Fase 0

A Fase 0 não pode aparecer no plano econômico como produtora de dado de mercado, feature, previsão, candidato, ranking, carteira ou backtest.

## Bloqueios explícitos

- Fase 0 → Fase 4 com feature econômica.
- Fase 0 → Fase 5 com previsão ou sinal.
- Fase 0 → Fase 6 com candidato.
- Fase 0 → Fase 7 com score/ranking.
- Fase 0 → Fase 8 com peso/ordem/posição.
- Fase 0 → Fase 9 com P&L econômico.
- Qualquer fase usando dashboard técnico como input de decisão econômica.
