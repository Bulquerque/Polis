# Fonte de verdade — P4 V14.6-RC1

A autoridade global permanece na P0. Dentro deste pacote, a ordem normativa é:
1. `contracts/` e `schemas/`;
2. `registries/`;
3. `contracts/MODULE_CATALOG.yaml` e `contracts/MODULE_IO_MATRIX.yaml`;
5. documentação de fase/subfase;
6. prompts.

Em conflito, contrato/schema prevalece. Existem exatamente três agentes, cada um com três subfases. Paths compartilhados só mudam por change request aprovado pelo Integration Lead.
