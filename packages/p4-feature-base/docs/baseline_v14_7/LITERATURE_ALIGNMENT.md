# Alinhamento com a literatura

A revisão profunda está dividida em:

- `LITERATURE_FOUNDATION_DEEP.md` — princípios e fronteiras;
- `VARIABLE_TAXONOMY_AND_RATIONALE.md` — famílias e variáveis;
- `RESEARCH_DECISION_MATRIX.md` — evidência para decisão;
- `registries/LITERATURE_REGISTRY.csv` — referências primárias estruturadas;
- `ENCODER_ARCHITECTURE_DECISION.md` — decisão de representação;
- `TEMPORAL_FOLDS_AND_HPO_POLICY.md` — validação e busca pequena.

A literatura não é usada para afirmar que uma anomalia continuará lucrativa. Ela fundamenta cobertura conceitual, mecanismos, riscos de data mining e políticas de teste.
