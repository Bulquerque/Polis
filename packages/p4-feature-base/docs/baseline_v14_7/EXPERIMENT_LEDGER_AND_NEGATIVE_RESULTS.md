# Ledger de experimentos e resultados negativos

O módulo P4.S9.M06 publica três artefatos:

- `p4_research_attempt_ledger`;
- `p4_rejected_feature_graveyard`;
- `p4_research_governance_report`.

Cada execução recebe `experiment_id`, hipótese, observador, parâmetros, dataset snapshot, folds, seed, pai, status e hashes. Tentativas canceladas contam. Resultados não podem ser apagados; correções geram novas entradas.
