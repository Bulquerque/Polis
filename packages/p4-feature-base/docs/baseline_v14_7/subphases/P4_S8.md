# P4.S8 — Representações cross-fitted

**Agente responsável:** `IMPLEMENTATION_STREAM`. Contratos e schemas permanecem read-only; mudanças exigem change request.

Construir folds cronológicos cross-fitted, orçamento pequeno e pré-registrado de hiperparâmetros e plano de treinamento sem acesso a targets futuros.

**Validações:** `outer_folds_expanding_and_chronological`, `inner_validation_time_ordered`, `search_budget_pre_registered`, `no_future_label_or_p5_metric`

### P4.S8.M02 — `family_pca_sparse_pca_builder`

**Validações:** `family_scoped_before_global`, `cross_fitted_past_only_fit`, `component_lineage_complete`, `sign_and_order_stability_reported`
